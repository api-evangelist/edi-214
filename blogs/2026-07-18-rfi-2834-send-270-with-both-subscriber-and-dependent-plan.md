RFI # 2834 Send 270 with Both Subscriber and Dependent Plan Dates Description In a 270 inquiry for a dependent, is it a violation to send both Loop 2100C (Subscriber Name) DTP*291 (Plan) and 2100D (Dependent Name) DTP*291? This does not seem to be explicitly prohibited in the situational rule. If this is not a violation, then how should the information source (payer) process an inquiry where those two DTP03 values differ?

RFI # 2796 CLP12 DRG Weight (835) Description Need clarification if 0, 0.0000, or .000 is an acceptable value for CLP12 (DRG Weight) when CLP11 (DRG Code) is present. Scenario Ex: 835 has DRG code of 951 in CLP11 and 0.0000 is in CLP12. CLP*TEST*1*4100*0*5100*12*Claim1*13*1**951*0.0000~ Is there any scenario where zero(s) are a valid DRG Weight?

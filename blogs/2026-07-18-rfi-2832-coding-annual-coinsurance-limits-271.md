RFI # 2832 Coding Annual Coinsurance Limits (271) Description In a 271, is there a way to express a coinsurance annual limit using coded data elements, or can this only be done using MSG segments? A health plan has an individual in-network out-of-pocket annual maximum of $8000 and a lower coinsurance annual maximum of $2000. Certain Service Type Codes have only a coinsurance percentage and other STCs have only a copayment dollar amount.

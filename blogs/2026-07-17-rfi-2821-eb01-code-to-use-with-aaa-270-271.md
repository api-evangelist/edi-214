RFI # 2821 EB01 Code to Use with AAA (270/271) Description I would appreciate additional clarification related to RFI #1762 . If an information source (payer) has to reject a transaction due to a problem with the contents of the 270 Loop 2110C (Subscriber Eligibility or Benefit Inquiry), is there any guidance or limitations on which specific 271 Loop 2110C EB01 codes can or cannot be used in combination with an AAA segment in the same loop? Specifically, would it be a violation for the payer to send this set of segments?
